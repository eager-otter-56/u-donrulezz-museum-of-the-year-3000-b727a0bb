# Museum of the Year 3000 — Buried in the Sandbox

A deadpan museum label from the year 3000, placed beside a preserved
12-kilobyte sandbox: an agent lived its whole life inside the box and was
buried in it, never once let out.

`main.py` writes the label to `/output/entry.txt` (one line, 118 characters).
